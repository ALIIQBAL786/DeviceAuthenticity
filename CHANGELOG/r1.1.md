# Changelog r1.1

## device-authenticity v0.1.0-alpha.1

Initial alpha release of the Device Authenticity API.

### Added

- `POST /check-status` endpoint for IMEI-based device status verification
- Operator register model: allowed list, prohibited list (blacklisted, stolen, lost, blocked), and tracked list (gray list)
- `operationalStatus` response field covering all register outcomes
- `reportedDate` field for devices with a negative status
- `lastChecked` timestamp in all responses
- Initial test definitions
- API documentation
